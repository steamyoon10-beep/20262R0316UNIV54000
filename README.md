# DINO SPRINT

선인장과 익룡을 피하며 달리는 반응형 브라우저 공룡 게임입니다. 별도 설치나 빌드 없이 `index.html`을 열면 실행됩니다.

## 조작법

- `Space` / `↑`: 점프
- `↓`: 숙이기
- `R`: 게임 오버 후 재시작
- 모바일: 게임 화면 터치

## 실행

정적 파일 서버에서 이 폴더를 열거나 `index.html`을 직접 실행하세요.

```bash
python -m http.server 4173
```

## 특징

- Canvas 기반 러너 게임
- 점진적으로 빨라지는 난이도
- 선인장과 익룡 장애물
- 거리 점수와 로컬 최고 기록
- 반응형 모바일 레이아웃
- Web Audio 기반 효과음
